# This folder contains all data used in the manuscript
- **BridgePier.tsv**: Bridge-pier dataset after eliminating an outlier sample
- **ds845_psdb-2014_version1.0.xlsx**: The original dataset downloaded from [USGS Pier-Scour Database (PSDb)](https://www.usgs.gov/publications/a-pier-scour-database-2427-field-and-laboratory-measurements-pier-scour)
  - Ref: Benedict, S.T. and Caldwell, A.W. A pier-scour database: 2,427 field and laboratory measurements of pier scour. In.: US Geological Survey; 2014.
